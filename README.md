# Refresh System Simulator

An Android prototype for exploring the user's proposed Refresh Theory through an interactive, educational system simulation.

## Current prototype
- Six learning stages: natural system formation, open-system exchange, refresh, stability/connections, information/memory, and the proposed consciousness model.
- Animated connected-node visualization.
- Pause/resume, refresh counter, and short/long timescale toggle.
- Clear note that the theory is proposed and the simulation is not scientific proof of consciousness.

## Build
Open this folder in Android Studio (recent version), allow Gradle sync, then run on an Android device or emulator.

- Application ID: `com.refreshsystem.simulator`
- Minimum Android: 7.0 (API 24)
- Target SDK: 35

This is a first source-code prototype. It does not yet include AdMob, a release signing key, or Play Store publishing setup. Those should be added after the core simulation is tested.
